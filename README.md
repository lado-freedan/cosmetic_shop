🛍️ Cosmetic Shop API
A production-ready REST API for an e-commerce cosmetic platform, built with Django & Django REST Framework.

🔗 Live API: https://cosmeticshop-production.up.railway.app/

Key Features:
JWT Authentication (SimpleJWT)
Product listing with filtering by category & brand
Custom User model (email-based auth)
Dockerized & deployed on Railway with PostgreSQL

Tech Stack: Django 6 · DRF · PostgreSQL · Docker · JWT
